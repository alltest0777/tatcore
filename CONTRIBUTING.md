# Contributing to TatCoin

Thank you for your interest in contributing to TatCoin.

We welcome contributions from developers, validators, technical writers, testers, and community members.

---

# Ways to Contribute

You can help by:

- Reporting bugs
- Improving documentation
- Fixing issues
- Developing new features
- Reviewing pull requests
- Running validator nodes
- Testing new releases

---

# Development Setup

Clone the repository:

```bash
git clone https://github.com/alltest0777/tatcore.git
cd tatcore
```

Build the project:

```bash
make install
```

Run the node:

```bash
tatcoind start
```

---

# Branches

Please create a separate branch for every feature or bug fix.

Example:

```bash
git checkout -b feature/my-feature
```

---

# Commit Messages

Use short and descriptive commit messages.

Examples:

```text
docs: improve README

fix: correct staking parameters

feat: add snapshot support
```

---

# Pull Requests

Before opening a Pull Request:

- Ensure the project builds successfully.
- Keep changes focused on a single topic.
- Update documentation if necessary.
- Write clear commit messages.

---

# Code Style

Please follow standard Go formatting.

Run:

```bash
gofmt ./...
```

before submitting your changes.

---

# Reporting Bugs

If you discover a bug, please open a GitHub Issue including:

- TatCoin version
- Operating system
- Steps to reproduce
- Expected behavior
- Actual behavior

---

# Feature Requests

Feature requests are welcome.

Please describe:

- The problem
- Your proposed solution
- Alternative approaches (if any)

---

# Community

Please be respectful and constructive in all discussions.

We aim to maintain a friendly and welcoming open-source community.
